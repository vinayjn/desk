# Standing desk

Control a standing desk from its physical keypad or the Desky macOS menu bar app.
The ESP32 relays keypad traffic and accepts height targets over Bluetooth.

- [firmware/](firmware/): ESP32-C3 firmware, wiring, and USB controls.
- [macos/](macos/): Desky Xcode project for macOS 26 or later.

Build and setup instructions are in each folder's README.
